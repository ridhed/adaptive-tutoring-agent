# 1. Dataset Input
**Dataset:** [Assistment2009](https://doi.org/10.57760/sciencedb.j00133.00253)

**Input Parameters:**

| Variable         | Type    | Description                               |
| ---------------- | ------- | ----------------------------------------- |
| `student_id`     | String  | Unique student identifier                 |
| `kc_id`          | String  | Knowledge component/skill tag             |
| `correct`        | Boolean | 0/1 ground truth                          |
| `time_seconds`   | Float   | Time from display to submission           |
| `attempt_number` | Integer | Attempts on the current problem           |
| `hint_count`     | Integer | Number of hints requested                 |
| `opportunity`    | Integer | Sequential opportunity to practice the KC |

**Derived Evidence:**

- `mistake_history`: Previous incorrect responses for the same student and KC
- `kc_success_history`: Previous correct responses for the same student and KC

**Discretization Rules:**

- `response_time`: FAST (< expected_time × 0.3), SLOW (≥ expected_time × 0.3)
- `hint_usage`: NO_HINT (0), HINT_USED (> 0)
- `attempts`: FIRST_ATTEMPT (1), REPEATED_ATTEMPT (> 1)
- `mistake_history`: LOW (< 2), REPEATED (≥ 2)
- `kc_success_history`: NO_PRIOR_SUCCESS (0), PRIOR_SUCCESS (≥ 1)

# 2. Error Patterns

{`possible_carelessness`, `possible_execution_error`, `possible_conceptual_difficulty`, `insufficient_evidence`}

**1. Possible Carelessness:**  
`correct = 0` AND `time_seconds < expected_time × 0.3` AND `attempt_number = 1` AND `hint_count = 0` AND `kc_success_history ≥ 1`

**2. Possible Execution Error:**  
`correct = 0` AND `time_seconds ≥ expected_time × 0.3` AND `attempt_number = 1` AND `hint_count = 0` AND `kc_success_history ≥ 1` AND `mistake_history < 2`

**3. Possible Conceptual Difficulty:**  
`correct = 0` AND (`mistake_history ≥ 2` OR `attempt_number > 1` OR `hint_count > 0`)

**4. Insufficient Evidence:**  
`correct = 0` AND none of the above conditions are satisfied

The agent estimates the most likely error pattern using fixed thresholds from current response and historical KC behaviour.
# 3. Hidden States

{`carelessness`, `execution_error`, `conceptual_difficulty`, `mastery`, `uncertain`}

# 4. Actions

{`ASK`, `HINT`, `TEACH_PRIOR`, `ANSWER`}
